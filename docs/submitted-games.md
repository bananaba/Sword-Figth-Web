| 카테고리 | 추정 비중 | 신호 |

| 비행/세일/드라이브 시뮬 (fly.pieter 클론) | 15 % | **레드오션 2순위** |

| 내러티브 / 마이크로게임 / 풍자 | 4 % | **Vibeware Silver — 출품 비중 대비 수상률 높음** |
| 협업/캔버스/MMO 라이트 | 3 % | 사회적 메카닉 |
| 트리비아/파티/기타 | 7-10 % | 멀티 트리비아 호응 |

### 그래픽 / 스타일
- Three.js 로우폴리 3D 압도적 (60 %+) — 수상작 3개 모두 로우폴리 3D
- 픽셀/2D는 소수 → VibeCanvas처럼 **차별화 도구**
- 사이버펑크 네온/레트로 80s 다수 — 톤이 한 장면에 보이는 게 수상작 공통점

### 멀티 vs 싱글
- 멀티 약 40 %, 싱글 60 %. 멀티 백엔드 분포:
  - **PartyKit / Cloudflare Durable Objects** — 신흥 1순위, 서버리스 실시간
  - 자체 Node + ws — 가장 흔함
  - Socket.IO — 클래식, 많음
  - **Colyseus** — 본격 멀티 (Vector Tango 류)
  - PeerJS — fly.pieter 모델 (서버비 0)
  - Supabase Realtime — 라이트

### 모바일
- levelsio Day 10 트윗에서 **모바일 동작 명시적 강조** → 가산점 / 누락 시 감점
- 실제 출품작 중 **30~40 %만 모바일 정상 동작** 추정 → **차별화 포인트**

- 2025: Cursor 압도적 + Bolt.new + Claude 3.5/3.7 / Grok / GPT-4 혼합. fly.pieter는 Grok + Claude
- 2026: Cursor 3 (다중 에이전트), Claude Code, Codex CLI 주류

## 5. 수상/바이럴 작품의 공통 패턴

1. **30초 룰** — 수상작 3개 모두 첫 30초 안에 코어 루프가 끝까지 보임
2. **명확한 톤/미학** — 한 장면 스크린샷에 컨셉이 다 보임 (네온 / WarioWare / 80s 벡터)
3. **친숙한 IP 메모리에 의존** — GTA, WarioWare, ATC. 새 장르 발명보다 AI 카피코딩으로 재현
4. **트윗 가능한 한 줄 컨셉** — "AI로 만든 GTA 택시 모드", "AI가 시키는 일을 하는 봇 게임"
5. **공유 동기** — 멀티 ATC, RT 잘 도는 짧은 영상

- **Karpathy**: **메타 작품** — 잼 자체의 정체성을 게임이 표현 (Vibeware의 "봇이 시키는 일")
- **timsoret**: 감정 / 분위기 / 시네마틱 한 컷
- **NicolaManzini (2026 신규)**: 멀티 친화 — Vibe Sail 출신

## 6. 컷오프된 작품 공통점 (피해야 할 함정)

- **로딩 실패** — 1차 컷의 절반이 여기서 탈락 ("many games didn't even load" — levelsio)
- 로그인 / 회원가입 강제 — 즉시 컷
- 모바일 깨짐 (iOS Safari 미테스트)
- 단일 도메인 위반 → 위젯 트래킹 불가 → 활동 지표 0 → 컷
- 게임 타이틀 / 메타데이터 부재
- "데모 같은 데모" — 코어 루프가 30초 안에 안 잡히면 컷
- "AI 만든 티" — placeholder 텍스트, missing 텍스처, console.error 잔존

## 7. 본 프로젝트 차별화 화이트스페이스

조사한 1,170개 분포를 종합하면 2026년에 노릴 만한 빈 자리:

**(a) LLM 네이티브 내러티브 / 메타 게임** — Vibeware가 Silver를 받았지만 출품 비중은 4 %.
"AI 면접관을 속이는 게임", "AI 매니저가 실시간 KPI를 던지는 게임" 처럼 **잼 자체 정체성을 게임으로 표현**하는 메타 작품 = Karpathy 취향 직격.

**(b) 로컬 1대 디바이스 비대칭 협동/배틀** — 폰을 컨트롤러로, 노트북을 메인 화면으로 (WebRTC + QR).
멀티 가산점 + 모바일 가산점 동시 확보. 출품작 거의 없음.

**(c) 리듬/오디오 게임** — 전체 출품 1 % 미만. AI 절차적 BGM(Suno/Udio) + 노트 게임은
**"AI가 진짜로 새 컨텐츠를 만든다"** 인상이 가장 강함.

**(d) 30초~3분 턴제 미니 로그라이크** — Slay the Spire / Balatro 라이트.
풀 3D 액션 레드오션 정반대. 모바일 호환·짧은 세션·트윗 클립 모두 강함.

**(e) 포털 메타게임** — 2026년 잼의 포털/웹링을 **메카닉 자체로 활용**:
"포털을 타고 다른 #vibejam 게임에 침투해 미션 수행" — levelsio가 인프라를 게임화하는 작품을 좋아할 가능성 큼.

**(f) Tripo3D 스폰서 활용** — 실버 스폰서. "내가 적은 단어가 5초 후 보스로 등장" 같은
**텍스트 → Tripo3D → 즉시 게임 등장** 메카닉은 스폰서 셔우트아웃 거의 보장.

### 결론

**3D FPS · 비행 · 드리프트 절대 회피.**
30초 안에 한 줄 컨셉이 잡히는
**(메타 / 내러티브 / 리듬 / 턴제 / 로컬 비대칭) × (모바일 + 포털 메카닉 + Tripo3D 통합)** 의
조합이 5인 심사위원 취향 모두를 만족시키는 좌표.
